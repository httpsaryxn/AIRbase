# Google Sign-In Setup Guide

Follow these steps to set up Google Sign-In for your React Native/Expo app:

## Step 1: Enable Google Sign-In in Firebase Console

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project: **airbase-5a905**
3. Navigate to **Authentication** > **Sign-in method**
4. Click on **Google** provider
5. Enable it and add your **Support email**
6. Click **Save**

## Step 2: Get Your OAuth Client ID

1. In Firebase Console, go to **Authentication** > **Sign-in method** > **Google**
2. Under **Web SDK configuration**, you'll see:
   - **Web client ID**: Copy this value (it looks like: `518778819608-xxxxxxxxxxxxx.apps.googleusercontent.com`)

## Step 3: Configure Your App

1. Open `src/screens/LoginScreen.tsx`
2. Find the line: `const clientId = '518778819608-xxxxxxxxxxxxx.apps.googleusercontent.com';`
3. Replace `'518778819608-xxxxxxxxxxxxx.apps.googleusercontent.com'` with your actual **Web client ID** from Step 2

## Step 4: Configure Redirect URI in Google Cloud Console

**IMPORTANT:** You need to add your redirect URI to Google Cloud Console for OAuth to work.

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your project (or the project associated with your Firebase project)
3. Navigate to **APIs & Services** > **Credentials**
4. Find your OAuth 2.0 Client ID (the Web client ID you copied earlier)
5. Click on it to edit
6. Under **Authorized redirect URIs**, add the Expo proxy URL:
   - The format is: `https://auth.expo.io/@anonymous/quiz-battle` (or your actual username/slug)
   - **Important:** Google requires HTTPS URLs, not custom schemes like `exp://` or `airbase://`
   - The exact redirect URI will be logged to the console when you try to sign in
   - Copy that exact HTTPS URI from the console and add it here
7. Click **Save**

**Note:** 
- The redirect URI must be an HTTPS URL (Google's requirement)
- Expo's proxy (`https://auth.expo.io/...`) provides this automatically
- If you see an error from auth.expo.io, check that the redirect URI is correctly added to Google Cloud Console
- The redirect URI format is: `https://auth.expo.io/@username/slug` where username might be `@anonymous` in development

## Step 5: Test the Implementation

1. Run your app: `npm start`
2. Try signing in with Google
3. The OAuth flow should open in a browser and redirect back to your app

## Troubleshooting

### Issue: "Redirect URI mismatch"
- Make sure the `scheme` in `app.json` matches what's used in the code
- For development, the proxy URL is automatically generated by Expo

### Issue: "Invalid client ID"
- Double-check that you copied the **Web client ID** (not iOS or Android client ID)
- Make sure there are no extra spaces in the client ID string

### Issue: OAuth popup doesn't close
- This is normal in development - the browser will stay open
- In production builds, it should close automatically

## Additional Notes

- For **production**, you may need to configure authorized redirect URIs in Google Cloud Console
- The current implementation uses Expo's proxy for development, which works automatically
- For **web** platform, `signInWithPopup` is used (no additional setup needed)
